This is just the Zend_Log component extracted from our fork of the Zend Framework 1 repo (https://github.com/gizmocraftcom/zf1).

The Firebug log writer package (`zendframework1-log-writer-firebug`, based on Zend_Wildfire) is not part of the gizmocraft forks and is no longer suggested. `Zend_Log_Formatter_Firebug` stays, it has no dependency on Zend_Wildfire.
